
# Marguerite 产品定位（PRD·为什么存在）

> 版本 v1 · 2026-09-03 · 本文件对应改进路线图 M0/A1。
> 与 [architecture.md](architecture.md)、README 保持一致；功能收敛讨论请引用 NOSO List。

## 一句话

Marguerite 是一个**终端优先、本地优先、中文友好的智能体工作台**：一个 Rust 核心引擎 + 四端统一入口（CLI / TUI / Tauri 桌面 / Web 控制台），把「对话编排、工具执行、模式治理、记忆与技能」全部装进一台自己能掌控的机器。

## 目标用户

- **本地优先的工程师 / AI 玩家**：不把代码、提示词、记忆委托给云端，数据留在自己机器上。
- **多端连续使用者**：在终端写代码、在桌面管会话、在浏览器看统计，四端共用同一引擎、同一会话、同一份记忆。
- **中文场景重配置者**：需要中文模型路由、中文技能/文档、以及可手控的护栏与模式系统。

明确**不服务**：纯非技术大众消费者、需要团队 SaaS 协同的企业买家（见 NOSO List）。

## 核心旅程（北极星：首次任务 90 秒内完成率）

1. **打开**：CLI 键入 `marguerite`，或启动桌面 / Web，进入即用界面，无任何无关演示数据。
2. **看懂**：主屏导航 ≤9 项（核心工作流），治理 / 实验室默认折叠，一屏理解「我能做什么」。
3. **发起**：空态引导卡给出第一步，直接描述任务（例如「帮我把这个目录按类型整理」）即可开工。
4. **完成**：引擎 拆解 → 执行 → 验证 → 沉淀，产出可靠、可回滚的结果。
5. **治理**：模式 / 信任档位决定「大胆 vs 保守」，统计面板归因每次任务的成本。

北极星指标 = **首次任务的 90 秒内完成率**：新手从打开到发起第一个有效任务 ≤ 90 秒。

## 差异化三句话

1. **四端一芯**：CLI / TUI / 桌面 / Web 共享同一套 Rust 引擎与会话——命令行的克制与桌面的富交互并存，而不是四套各说各话的工具。
2. **模式即信任**：Work / Research / Automation / Safe / Bloom 五种运行模式把「Agent 自主度」变成用户可拨的开关，配合 PlanGate / CompletionGate 做到胆大心细。
3. **记忆与技能本地闭环**：三层记忆 + 技能/插件 JIT 触发 + Python 侧车全部落在本地，中文场景开箱即用。

## NOSO List —— 绝不做的清单

> 新增功能或改动前，PR / issue 必须自答：「这违反 NOSO 吗？」违反即拒绝或降级。

1. **不做云端托管 / 强制账号**：数据默认留在本机，绝不明文把会话私有内容隐式上传。
2. **不做无关娱乐上主屏**：德州扑克、鲸鱼娘、视觉取证等玩具仅限「实验室」折叠分组，不占主屏导航；可卸载，不物理删除。
3. **不做「为演示而演示」的假数据**：GUI 首启无任何无关演示会话；空态引导真实任务。
4. **不做第四套独立前端**：双前端应收敛为统一基座，禁止再造互不通用的 UI。
5. **不以牺牲工程质量堆功能**：任何改动须保持测试基线不回退、vue-tsc 0 错、文档漂移 0。
6. **不做不可回滚的破坏性自动作**：高风险动作必须过 PlanGate / CompletionGate 与模式护栏。
