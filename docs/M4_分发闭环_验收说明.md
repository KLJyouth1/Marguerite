## 5. 代码签名现状与接入步骤（可完成项④）

### 5.1 现状（2026-09-04 实测）

- 发布版 exe（40 MB）：`Get-AuthenticodeSignature` → `Status: NotSigned`
- 安装器 exe / msi：`Get-AuthenticodeSignature` 均已验 `Status: NotSigned`
- 本机证书库 `Cert:\CurrentUser\My`、`Cert:\LocalMachine\My`：无 Code Signing 证书
- 仓库与隔离目录：无 `.pfx` / `.p12` / `.crt` 签名私钥文件
- `signtool.exe`：存在于 Windows Kits（可用），签名工具链就绪

### 5.2 就绪条件
获得 Authenticode 代码签名证书（推荐 OV/EV，EV 免 SmartScreen 信誉建立期；个人/组织均可的 OV 亦满足基础签名）：

1. 采购/导入证书（.pfx 或由 CA 提供），并安装到本机证书库或持有其私钥
2. 获取 `certificateThumbprint`（`Get-PfxCertificate` 或证书管理器中「指纹」）与受信任时间戳服务器 URL（如 `http://timestamp.digicert.com`）
3. 在 `gui/src-tauri/tauri.conf.json` 的 `bundle.windows` 追加：

```json
"windows": {
    "webviewInstallMode": { "type": "offlineInstaller", "silent": true },
    "certificateThumbprint": "<指纹>",
    "digestAlgorithm": "sha256",
    "timestampUrl": "http://timestamp.digicert.com"
}
```

4. 重新 `scripts/package_app.cmd` 产出签名安装器
5. 验证：

```powershell
Get-AuthenticodeSignature "D:\Downloads\Marguerite\dist\Marguerite_0.2.0_x64-setup.exe"
# 期望 Status=Valid, SignerCertificate 为持有证书
```

> 说明：Tauri v2 会在 `cargo tauri build` 阶段自动用 certificateThumbprint 签名 MSI/NSIS 及 exe；如需更新通道（Step 4 可选）另行配置 `TAURI_SIGNING_PRIVATE_KEY` + `createUpdaterArtifacts`。
