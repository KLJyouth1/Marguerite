# 记忆系统

Marguerite 采用三层记忆架构：感知记忆 → 短期记忆 → 长期记忆，分层存储、逐级沉淀，检索时按置信度排序并自动降级。

```
┌─────────────────────────────────────────────┐
│ 感知记忆 (SensoryMemory)                     │
│ 当前会话上下文 · SQLite · 读写 < 1ms         │
└────────────────────┬────────────────────────┘
                     │ 会话结束 / 周期固化
                     ▼
┌─────────────────────────────────────────────┐
│ 短期记忆 (ShortTermMemory)                   │
│ FTS5 全文搜索 · 最近 N 个会话索引             │
└────────────────────┬────────────────────────┘
                     │ 自动摘要与索引（后台维护）
                     ▼
┌─────────────────────────────────────────────┐
│ 长期记忆 (LongTermMemory)                    │
│ 向量化存储（本地特征哈希）· 余弦相似度检索     │
│ 无外部 embedding 依赖                        │
└─────────────────────────────────────────────┘
```

## 感知记忆（`core/src/memory/sensory.rs`）

- 存储当前会话的上下文消息，SQLite 持久化。
- 设计目标：快速读写（< 1ms）。
- 典型用法：运行时即时写入，会话内随时取用。

## 短期记忆（`core/src/memory/short_term.rs`）

- 基于 SQLite **FTS5** 全文搜索，按关键词快速召回最近会话。
- 维护最近 N 个会话的索引，支持模糊匹配。

## 长期记忆（`core/src/memory/long_term.rs`）

- **向量化存储**：内置轻量语义嵌入——文档切块 → 特征哈希（256 维）→ L2 归一化 → SQLite 持久化。零外部模型依赖，冷启动即可用。
- **余弦相似度检索**：`search(query, k)` 返回按相似度降序的条目，低于阈值（0.35）视为无相关。
- **自动摘要与索引**：后台异步维护，避免阻塞主链路。
- **固化入口**：`consolidate(&sensory)` 将感知记忆沉淀为长期记忆。

## 分层检索

```
检索请求
  │
  ▼
感知记忆（命中即返回，最快）
  │ 未命中
  ▼
短期记忆（FTS5 全文匹配）
  │ 未命中
  ▼
长期记忆（语义向量匹配，带置信度）
  │ 置信度低
  ▼
自动降级：返回空结果或触发 LLM 重新归纳
```

- **置信度分数**：长期记忆返回每条命中条目的相似度 `score`。
- **自动降级**：下层未命中时逐级回退，最终降级为「无记忆」，由模型从零处理。

## 会话持久化（`core/src/persistence/session.rs`）

- 会话快照保存与恢复（含上下文与状态）。
- 会话列表管理（list / delete）。

## 配置

```yaml
memory:
  sensory_path: "memory/sensory"           # 感知记忆存储路径
  short_term_path: "memory/short_term"     # 短期记忆存储路径
  short_term_max_sessions: 2000            # 跨会话检索的留存上限，超出按 updated_at 淘汰最旧的
```

> 短期记忆的全文索引（SQLite FTS5）额外索引一份**分词后的副本** `search_text`，
> 原始 `summary` 只用于展示。原因：FTS5 的 `unicode61` 会把一整段没有空格的中文当成
> **一个**词元，直接索引原文时中文查询恒为 0 命中。用户文本进入检索前会先编译成
> FTS5 表达式（逐词元加引号、丢弃 `and`/`or`/`not`/`near`），所以它永远是数据、不是语法。
