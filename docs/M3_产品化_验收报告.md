## 1. D1 行为事件（12 个 + 审计日志 + WebUI 最近活动时间线）— 完成

### 1.1 12 个产品行为事件

`core/src/events/product.rs` 定义 12 个事件常量并集为 `PRODUCT_EVENTS: [&str; 12]`：

| # | 事件 | 常量 |
|---|------|------|
| 1 | 任务发起 | `task.initiated` |
| 2 | 计划确认 | `plan.confirmed` |
| 3 | 工具调用 | `tool.call` |
| 4 | 任务完成 | `task.completed` |
| 5 | 任务失败 | `task.failed` |
| 6 | 任务取消 | `task.cancelled` |
| 7 | 切换 Mode | `mode.changed` |
| 8 | 切换信任档位 | `trust.changed` |
| 9 | 审批请求 | `approval.requested` |
| 10 | 审批通过 | `approval.granted` |
| 11 | 审批拒绝 | `approval.denied` |
| 12 | 成本预算告警 | `budget.warning` |

- 事件→信封类型映射 `envelope_type`：计划→`Plan`、工具调用→`ToolCall`、完成→`Done`、失败→`Error`、审批→`Approval`、其余→`Status`。
- 单测 `product_events_table_has_12_kinds` 断言集合恰为 12 个（防删防增）。

### 1.2 审计日志（统一事件总线 + 本地落盘 双写）

- 双写入口 `emit(kind, session, fields)`：一次调用同时①发布到全局事件总线（`Envelope`）；②追加本地审计日志。
- `audit(kind, session, fields)`：仅落盘，供已广播事件（如 `mode.changed`）复用。
- 审计后端 `core/src/audit_store/`：**独立 append-only SQLite（`~/.marguerite/audit.db`）+ SHA-256 哈希链**；触发 UPDATE/DELETE 时 `RAISE(ABORT)` 强制只追加。
- 审计单测 `audit_store/tests.rs` 校验哈希链与 append-only。

### 1.3 WebUI「最近活动」时间线（同源可对账）

- RPC `activity.recent`（`core/src/gateway/methods.rs`）→ `events::product::recent(limit)`：直接从审计日志 `audit_log` 表倒序读取，过滤 `event.*` 归类为产品事件，前端无需二次落库。
- WebUI `RecentActivityPanel.vue`：渲染 `<ol class="activity-list">` + `<li class="activity-row">` + `<time datetime>`，带角色化错误提示。
