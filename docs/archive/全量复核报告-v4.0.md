## 二、本轮修复项（P0 API Key 401 致命错误）

### 缺陷描述
用户首次启动时无 API Key，发送消息直接触发 deepseek-v4-pro 的 401 致命错误，无友好提示。

### 修复内容

#### Rust 后端（core/src/gateway/chat.rs）
- `send()` 方法在 `client_message_id` 解析后、`thinking` 开关前插入 `ctx.config.model.api_key.trim().is_empty()` 前置校验
- 空键返回 `RpcError::new("API_KEY_MISSING", "...")`，不触发后台任务
- 新增测试 `test_send_rejects_empty_api_key`：空 key → `is_err` + code=`API_KEY_MISSING` + 无后台任务

#### Vue 前端（webui/src/utils/chat/errors.ts）
- 新增 `API_KEY_MISSING = 'API_KEY_MISSING'` 错误码常量
- `localizedChatErrorMessage` 新增 `API_KEY_MISSING` 分支，返回 `i18n.global.t('chat.errors.apiKeyMissing')`

#### i18n 六语言翻译（webui/src/locales/*.json）
- `chat.errors.apiKeyMissing` 键在 en/zh-Hans/ja/fr/de/es 六语言全部添加

#### 验证证据
- `cargo test -p marguerite-core --lib` → **2426 passed / 0 failed / 17 ignored**（+1 为新增测试，零回归）
- `vue-tsc --noEmit` → **0 error**
- `vitest run` → **3175 passed / 305 files**（零回归）
- `e2e_fusion_methods_over_ws` 测试仍通过（零回归）
