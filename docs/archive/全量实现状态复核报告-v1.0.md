## 七、禁止误判清单（复核基准）

1. **Goal 引擎 ≠ Goal 产品**：无网关方法、UI、run_autonomous 接管和事件验证，仍是底座
2. **Vision client ≠ 多模态开箱即用**：必须证明 image part 从 WebUI 到模型再回到 UI 的端到端链路
3. **Model seed ≠ Omni 路由**：有模型名不代表有能力档案、权重、契约、fallback 和可观测性
4. **Workbench registry ≠ 三栏工作台**：注册机制和可用页面是两件事
5. **cargo check 通过 ≠ M0 完成**：WS 夹具、台账清理、p0-gate 稳定性仍要有证据
6. **门禁 PASS ≠ 业务完成**：418 条例外中有 25 个 emoji、36 个色值、4 个 easing 必须逐条清账
7. **策略文档的市场数字 ≠ 代码验收证据**：G1/G2/G3 只认 Bench、测试、构建、安装验收结果
