本次合并修复的关键缺陷

1
英文 Windows fsutil 输出不匹配 → disk_free 测试失败
根因：代码只匹配中文"可用字节数"和英文"Available"，不支持"Free bytes"格式。修复：添加 lower.contains("free bytes") 匹配 + 重写 extract_number → extract_number_after_colon，只取冒号后、括号前的主数值，不受括号辅助数字污染。
2
全局 PrefixCache 共享状态污染 → 3 个 flaky 测试
根因：gateway_prefix_cache() 是 OnceLock 进程级单例，chat_complete_cached() 在 semantic_layer() 已安装时忽略测试本地 cache、转用全局语义层。先行测试填充缓存后，后续测试 HIT 跳过真实 LLM 调用。修复：为 PrefixCache 和 MultiTierCache 添加 #[cfg(test)] clear() 方法，在 3 个 flaky 测试开头调用清除全局缓存。
3
prefix_hits 断言指向错误缓存实例
根因：note_prefix() 调用在全局 effective 缓存上（语义层安装时），但测试检查本地 cache.stats()。修复：断言改为通过 semantic_layer().exact_arc() 或 fallback 本地 cache 动态获取实际计数的缓存实例。
4
Clippy L3 零警告（10 个 warning 全部修复）
routing_contract.rs 添加 #[allow] · audit_store 添加 is_empty() · doctor/mod.rs 提升 #[allow] 到函数级 · rollback_policy.rs &String→&str + to_string() · plan/runner.rs 2x loop→while let
5
文档/代码 CLI 漂移修复
cli-tui-optimization-plan.md 移动到 docs/planning/，消除 check-doc-cli-drift.py 检测的路径不一致
