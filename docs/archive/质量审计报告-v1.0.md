## 五、Critical 问题（2 项，待修复）

### QA-001：侧栏弹出菜单 z-index 冲突

- **文件**：`webui/src/assets/base.css:566` + `webui/src/styles/control-visual-system.css:859`
- **问题**：`.sidebar-more-popover`（z-index:210）与 `.sidebar-row-menu`（z-index:210）共用相同层级
- **影响**：展开 More 菜单后 hover 历史记录行操作菜单时，两个菜单可能互相遮挡
- **建议**：将 `.sidebar-row-menu` 上调至 215，或 `.sidebar-more-popover` 下调至 205

### QA-002：壁纸沉浸视图与终端主题背景 z-index 冲突

- **文件**：`webui/src/views/WallpaperView.vue:178` + `webui/src/themes/terminal/world.css:38`
- **问题**：`.wall-immersive`（z-index:9990）被终端主题背景（z-index:9998）覆盖
- **影响**：切换至 Terminal 主题后进入壁纸沉浸视图，壁纸内容被遮挡
- **建议**：将壁纸视图提升至 10000，或终端主题背景降至 900 以下
