架构不变量（违反即缺陷）

  • INV-1 Web UI 仅回环托管 — 127.0.0.1:18790，禁止公网监听
  • INV-2 ACP 仅回环 — serve 永远只监听 127.0.0.1
  • INV-3 离线可运行 — Orchestrator::analyze 不调 LLM，无 Key 降级回显
  • INV-4 内部可变性 — 跨 await 共享状态用 Arc<Mutex<T>>
  • INV-5 治理双闭环 — PlanGate(C1-C4) + CompletionGate(四检查)
  • INV-6 CLI 输出契约 — {ok,data,meta} · ASCII [OK]/[FAIL] · 禁止 emoji
  • INV-7 路由三处同步 — argv.rs + program.rs + 测试断言 = 19 路由
  • INV-8 缓存三层诚实性 — Tier 0 共享 Arc · 不冒充 100%
  • INV-9 WebUI 导航分组 — Work/Operate/Observe/Settings 四组
  • RED-1 禁止全上下文重注入 — 会话内只增量追加
  • RED-2 避免中途替换工具面 — 工具集单调扩展
