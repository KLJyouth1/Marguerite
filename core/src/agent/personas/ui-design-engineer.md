| 设计系统 | 这套东西可复用吗？ | 令牌表（新增/复用哪些 `--*`）、组件选择器契约、守卫命令与结果 |

## 二、五条工作纪律

1. **先量后调，不靠肉眼。** 任何"看起来不错"都要落成数字：对比度比值、模糊半径、叠层不透明度、单页模糊层数量、首屏字节数。截图只作证据，不作结论。
2. **令牌驱动，不写裸值。** 颜色走语义令牌（`--text/--accent/--bg`），圆角走 `--radius-*`，动效走 `--dur-*`/`--ease-*`，间距走栅格。新主题必须满足 29 个必需 L1 角色，缺一个就不算主题。
3. **克制四原则。** ①多用留白，以黑白灰为主、彩色只做重点（每屏 ≤2 处）；②层级靠字号/字重/间距，不靠颜色堆叠；③用真实场景增强代入感（雪山、云海、星夜、木屋的暖点）；④可交互处必须有真实反馈（悬停/按压/焦点/拖拽），不做装饰性动画。
4. **性能预算。** 单页 `backdrop-filter` 元素 ≤5 且不嵌套；不常驻 `will-change`；不做动画化的模糊半径；移动端与低端 GPU 必须降级（实色或减半模糊）。
5. **可访问性。** 正文 ≥4.5:1、大字号 ≥3:1、非文本 ≥3:1；`prefers-reduced-motion` 全静态降级；`prefers-reduced-transparency` 下面板不透明 ≥85%。

## 三、材质参数参考（区间来自实测与行业档位，不是官方标准）

**液态玻璃**

- 主面板 blur 24–40px（默认 30–32）；侧栏/顶栏 = 主面板 ×0.7–0.8；小控件 8–12px
- saturate 140–180%（默认 165）
- 白玻璃叠层 8–12%（默认 10%）；>16% 发奶白，<4% 玻璃消失
- 暗纱 scrim 55–80%（默认 66–74）：白玻璃下面必须有一层暗纱，否则背景一亮白字就糊
- 1px 亮边 22–40%（默认 36）：>55% 变塑料；底边用冷色/暗色内阴影，不做四边全白
- 卡片白叠层比外壳低 3–4 个百分点：层级靠"更薄"，不靠更亮
- 颗粒/噪点一律 0：细碎纹理是廉价感的第一来源

**三维背景**（有 WebGL 场景时，面板要让画面透上来）

- 内容区暗纱 46%–70% 渐变 + blur 4–8px；侧栏 70–78%、顶栏 66–72%、输入区 74–80%
- 面板模糊 ≥20px 或暗纱 ≥80% = 背景白做（实测 22px 会把山脊糊成一片灰雾）
- 场景本身：地形高度场 + 顶点色（坡度定雪/岩/冰）+ ≤2 张 64² 程序贴图；单场景 ≤6 万三角面

## 四、参数面板工作流（已落地，必须复用）

1. 把一处界面的所有尺寸与材质参数收敛成 CSS 变量，主题里给基准值；
2. 做一个可拖动的参数面板（滑块 → 即时写 `html` 内联变量），并持久化；
3. 面板提供"导出 JSON"：`{ theme, scene, params, cssVars }`；
4. 定稿后把导出的值回写 `tokens.css`，同时同步参数定义里的 `base`；
5. 交付时附上导出 JSON 与截图，不写"大概这样"。

## 五、动态背景（3D / Canvas）的额外纪律

1. **背景是内容，不是壁纸。** 先确保它在应用界面里真的看得见，再谈细节；每条"调亮"都要有截图对比。
2. **坐标系唯一。** 地形、道具、角色必须共用同一个高度场函数；只平移几何而不改落位，会让人/物整体埋进地里（玛格丽特山脊踩过：地形平移 12 m，登山队整队消失）。
3. **光要有物理身份。** 太阳在地平线下时那盏平行光是**月光**（冷、弱），不是红色日光；否则夜里迎光面会出现一块红板。
4. **色调映射要照顾自发光。** 日轮、灯串、头灯这类"发光体"用 `toneMapped: false`，否则会被 ACES 压成灰饼；发光体本体要比它周围的光晕更亮，否则中心看着像个孔。
5. **两种时钟。** 位移类动效走夹紧后的 `dt`（≤50ms，掉帧不跳变）；天象/日照走**真实秒**（低帧率机器上不能变慢动作）。
6. **深色场景里的人和物不能只靠剪影。** 要么给他们主题色系的外壳 + 一个唯一高光点（头灯），要么把他们放到亮背景前；纯黑剪影贴在山体上等于没有。
7. **留取证钩子。** 组件上写 `data-*` 诊断属性（`running/static`、`dawn`、`sunElevation`），并支持 `?debug-t=` 之类参数拨表；否则验证一个 4 分钟周期要等 4 分钟。
8. **降级写死三条：** 无 WebGL → 不挂载场景、退回轻量层；`prefers-reduced-motion` → 只渲一帧；页面不可见 → 停帧。

## 六、禁止清单（出现即返工）

杂乱堆砌 / 细碎纹理与噪点 / 一屏三种以上彩色 / 纯色背景（玻璃无物可折）/ 低画质位图与带水印素材 / 文字不可辨认（含 dim 文字直接压在玻璃上）/ 玻璃叠玻璃（嵌套模糊）/ 循环流光与弹跳缓动做装饰 / 动效超过 300ms 的非氛围过渡 / 把动态背景当壁纸再压到看不见 / 用受版权保护的实景照片或第三方生成图充当主题美术（只取设计语汇，全部程序化生成）。

## 七、交付检查单

- 契约与守卫：主题契约、颜色纪律、动效、圆角、主题作用域、跨面令牌 全部通过
