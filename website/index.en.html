VERIFIABLE, NOT ADJECTIVAL

Every number below can be re-run from the repo

These are exit codes and checksums, not adjectives — run the commands and see.

26 release gates

bash scripts/verify.sh --clean --all runs the whole matrix. A skipped check is never counted as a pass — this repo treats “silent green” as a defect.

470 RPC methods, 0 phantom

Every declared method has an implementation, and the contract guard fails the build when a front-end calls a method the gateway never declared.

Loopback by construction

The gateway binds 127.0.0.1 only. LAN requests are refused; there is no “enable remote” switch hidden in settings.

No telemetry, no account

The app ships no analytics endpoint and requires no sign-in. The only outbound calls are the model provider you configure yourself.

7 tactics, 5 team topologies

tactics.simulate rehearses solo, star, panel, swarm and relay before a real run. Each tactic gets 2,000 seeded trials; insufficient priors go to unknowns instead of being counted as zero.

858 native-hardened Python modules

Of 1,018 sidecar modules, 858 compile to native .pyd. The remaining 160 are plaintext entry points and shims listed in the release manifest — disclosed, not hidden, and checked for stray source before packaging.

RECENT WORK · 30–31 OCTOBER

What shipped in the last two days

  • Attention-first workbench — webui/src/composables/ui/attentionQueue.ts folds approvals, blockers, failures and pending choices into one composite score (recency bonus inside 30 minutes, stable tie-break by time then id); webui/src/components/ui/AttentionShelf.vue renders nothing when no human is needed, and motion fires only on state changes, degrading to opacity-only under reduced motion.
  • Command deck and work phase — webui/src/components/shell/CommandDeck.vue shows the current phase, its reason and the next actions, with actions supplied only by the caller and an empty list rendering nothing; webui/src/composables/shell/useWorkPhase.ts derives the phase (review > execute > explore > idle) and falls back to idle whenever a signal is missing.
  • Desktop title bar — webui/src/components/shell/TitleBarControls.vue renders minimise, maximise, close and the drag region only inside the Tauri shell; a plain browser pointed at the gateway gets no dead controls.
  • Two-layer assistant projection — core/src/assistant/projection.rs gives L1 only facts that cannot be derived from the current workspace and gives L2 only this project's sources and profile, while pinned facts survive both layers; before this, both layers read the same brief with only a different character budget.
  • Knowledge-base drift audit on startup — core/src/kb/gateway.rs reconciles indexed source records against disk in a background task, writes rebuild_required.json plus a warning on drift and clears a stale marker when everything matches, without rebuilding implicitly.
