产 品 能 力

一个核心，四种硬功夫

不是功能清单，是写进代码、能在你自己机器上验证的事实。

一个核心，两种外壳

Rust 内核同时产出库与二进制，CLI 与 Tauri 桌面共用同一引擎——桌面端不另起后端进程。

本地优先网关

内嵌网关默认只监听 127.0.0.1:18790。局域网内其他机器扫不到，你的代码不为了「检索」离开这台机器。

分层记忆

感知、短期、长期三层记忆。长期记忆用本地特征哈希向量化做余弦检索，不依赖外部 embedding 服务。

幻觉护栏

语法、语义、事实、契约四道闸依次过闸。不过闸就进修复循环：规则修复最多两次，仍不过再交给模型。

下 载 器

片头播完一整遍，才打开安装界面

下载器不只是进度条。它把这支片子在你的屏幕上完整放一遍。

循环播放，不抢戏

片子循环播放、默认静音；右下角可开声音。下载进度压在画面上层，不遮挡镜头。

下载再快，也要等

即使第一遍还没放完就下载完了，也会等片头播完才继续——这是刻意的节奏，不是卡住。

只从发布仓库取货

下载器直连 GitHub Releases，读出该版本安装包与 SHA256，下载完先校验再交给安装界面。

同一套内建在桌面端

桌面端「检查更新」里的下载也会走这个下载器，升级路径与首次安装保持同一套节奏。
