# Background Music Library

Audio files in this directory are bundled into the Control UI build and served
alongside the app's static assets.

## Built-in catalog (shipped with the app)

This manifest ships **four original tracks**, synthesised from scratch by
`scripts/generate-music.mjs` (no samples, no licensed material — see
`scripts/GENERATOR.md` for the pipeline, date and provenance). They are
released to the public domain under **CC0 1.0**: you may redistribute, remix
and use them for any purpose without attribution.

| Track | Style | Length |
|---|---|---|
| Dusk Pad | slow ambient pad | 75 s |
| Neon Arpeggio | synthwave arp, 100 BPM | 80 s |
| Lo-fi Drift | lazy chill beat, 76 BPM | 80 s |
| Focus Pulse | steady electronic pulse, 112 BPM | 85 s |

A fifth "track" — the runtime ambient pad (`__synth__`) — is generated by the
Web Audio API (`src/composables/useAmbientSynth.ts`); it ships no audio file.

## Adding your own tracks

Drop legally-obtained audio files into this directory and create
`playlist.local.json` (it fully replaces this manifest when present):

```json
{
  "tracks": [
    { "id": "my-track", "title": "My Track", "src": "my-track.mp3" },
    { "id": "my-stream", "title": "Some stream", "src": "https://example.com/track.mp3" }
  ]
}
```

- `id` — stable unique key; the last-selected track is remembered by id.
- `title` — display name in the picker menu.
- `src` — either a filename relative to this directory (bundled at build
  time) or an absolute `https://` URL (streamed at runtime). Other absolute
  URL schemes, root-relative paths, path traversal (`.` / `..`, including
  encoded or backslash forms), and scheme-relative URLs are ignored. Nested
  subdirectories such as `album/track.mp3` are supported.

Playing an HTTPS stream contacts that third-party host directly and exposes
ordinary request metadata to it, including your IP address and browser user
agent.

The first non-pad entry in `tracks` is the default selection. A track whose
file is missing simply fails to play; the music control itself always works
and can also play an ad-hoc local file via "Choose local file…".

The player is off by default — enable it under Settings → Appearance →
Background music, or via the command palette.
