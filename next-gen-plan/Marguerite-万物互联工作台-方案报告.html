04 · Edge Cases

特殊人群与特殊场景：无障碍作为一等公民

竞品只宣传「配色好看」，Marguerite 做「色觉安全 + 输入自由 + 紧急停止」。每类人群落到具体功能与代码层，不停留在名词。合规对标 WCAG 2.2 AA、GB/T 37668-2019、工信部适老化规范。

视障 / 低视力

功能：全局 aria-label 语义审计；流式输出区 aria-live 节流播报（审批/错误用 assertive）；3D 画布在屏幕阅读器模式下替换为文字状态卡；三档字号（14/18/22px）+ 纯黑高对比主题；全局 Alt+空格语音指令条。

听障

功能：视觉提醒中心（所有声音事件同时发顶部横幅 + 任务栏脉冲）；实时字幕面板，说话人区分用颜色加姓名标签；错误不只红字，配图标 + 文字 + 修复按钮。

运动障碍 / 肢体障碍

功能：全键盘可达 + 快捷跳转主区/侧栏/审批；易点模式目标 ≥44×44px；拖拽全部有等价按钮（WCAG 2.5.7）；dwell clicking 悬停即点预留；focus ring 对比 ≥3:1。

老年人（长辈模式）

功能：侧栏只留 3 入口（说话 / 昨天的文件 / 叫孩子来帮我）；字号 20px 起、按钮 60×60、无动效；方言语音大字麦；危险操作二次确认 + 常驻撤销；6 位协助码子女远程只读代点（双人确认）。

儿童（少儿模式）

功能：沙箱限定 ~/Marguerite/儿童工作区/，禁全局装包与白名单外联网；少儿导师人格比喻讲解；家长 4 位 PIN 控时长 + 周报；无内购/无社交/无广告。

神经多样（ADHD/自闭）

功能：F9 专注模式只留当前面板；感官友好开关（关动效/声音/彩色背景）；大任务自动展开 checklist 进度条；「每屏只一个主按钮」原则。

色盲 / 色弱

判断：品牌蓝(#60A5FA)+橙(#F97316)本身色觉安全；风险在状态绿/红。功能：颜色绝不单独承载信息（WCAG 1.4.1 A），状态点加图标+文字；色觉安全主题把 ok 改蓝青；图表用线型/纹理区分系列。

方言 / 多语言

功能：离线方言 ASR 可选包（Fun-ASR-Nano 800M 支持 7 大方言+26 口音；sherpa-onnx int8 粤语/四川话），~500MB 模型断网可用；中英混说自动识别；ASR/TTS provider 可插拔。

离线 / 弱网 / 低配

功能：三档模型自动降级（本地 Ollama Qwen3 量化）；写操作 SQLite 同步队列，断网可恢复；资源三档自动探测，轻量档关 3D、整段渲染；BitNet 1.58bit 在 4GB RAM 可跑。

政企内网 / 国产化

功能：气隙模式一键禁外网 + 出站白名单；全量 JSONL 审计可导出 CSV；三架构交叉编译（x86/ARM64/LoongArch）适配麒麟 V10 / 统信 UOS；国密加密与 SSO 钩子预留。

安全紧急场景

功能：高危动作默认暂停等批准、超时 fail-closed；Esc×2 全局紧急停止 + 自动回滚快照；危险边界白名单（禁访问文档/D盘）作 prompt injection 物理防线。

左撇子 / 低视力补充

功能：菜单栏/停靠面板可整体镜像翻转（CSS direction + 布局变量）；仅放大聊天区不动侧栏；prefers-reduced-motion 自动关转场。

06 · Architecture

目标分层架构：六层

从传输底座到多端交互，每层职责清晰。新增能力只能多层扩展，不破坏现有 invariant（回环铁律、缓存诚实性、路由三处同步）。

L6
多端交互层
CLI / ratatui TUI / Tauri 桌面 / Web 控制台 / 移动端遥控；3D 岛屿 + 桌宠 + 长辈/少儿/专注/高对比/色觉安全主题
L5
安全治理层
PlanGate（宪法 C1–C4）+ CompletionGate；设备危险 L0–L3 + 跨引擎审批合并 + 审计日志 + RBAC
L4
记忆与认知层
感官/短期/长期/跨项目 + Hebbian synapse；家庭记忆 MCP + 个人知识图谱召回进岛屿
L3
Agent 编排与协作层
Orchestrator + 子代理/团队；Bloom 三段锚定 + 并行扇出 + A2A agent 卡片 + 元-harness
L2
统一工具-协议总线
Capability Schema（tool/resource 原语）；MCP client + MCP server 双向 + A2A well-known 卡片
L1
设备互联接入层（可插拔 adapter）
Home Assistant(REST/WS/MCP) / MQTT / 像素 computer_use / 无障碍树 UI / ADB 手机 /（远期 Modbus / OPC-UA / Tesla / ROS2）
L0
传输与安全底座
仅 127.0.0.1 网关 + LAN 出向 + 凭证加密隔离；离线可运行，无 key 降级回显

8 个可并行研发任务包 WP1–WP8

每个 WP 含目标 / 接口契约 / 依赖 / 代码落点 / 验收。橙色顶边 = 关键路径上的核心包。

WP1设备接入总线（核心，最早启动）
目标：打通 Home Assistant，做第一个物理世界 adapter；定义统一 Capability Schema 与危险等级。
契约：新增 core/src/devices/：DeviceRegistry + Adapter trait（list_entities/call_service/subscribe_events）；Capability schema JSON（id/name/domain/read/write/hazard_level 0-3/transport/last_seen）；RPC devices.list / devices.call / devices.subscribe，WS 事件 device.state_changed。
依赖：无（立即并行）　落点：core/src/devices/{mod,registry,adapter_ha}.rs；control-center 新增「设备」岛建筑
验收：接真实 HA 后 devices.list 返回灯/开关；devices.call 开关灯 ok；lock 自动标 hazard=2；verify.sh --core 全绿；新增集成测试 20+。
WP2MCP / A2A 双向化
目标：内部设备总线既当 MCP client（接外部 server）又暴露为 MCP server；实现 A2A agent 卡片发现。
契约：MCP server 把 devices.* 暴露成 tool；/.well-known/agent-card.json（技能/认证/能力：流式/文件/工具）。
依赖：WP1（Capability Schema 定义完）　落点：core/src/mcp/ 新增 device 桥；core/src/serve/a2a/
验收：外部 MCP client 能调 Marguerite 控灯；A2A 名片可被另一 agent 拉取；MCP 工具策略仍走 ExactOnly（invariant §3.8）。
WP3计算机操控双轨增强
目标：在像素 patch 网格 computer_use 之上，增加「无障碍树 UI 结构」通道，提升稳定与省 token（参照 agent-desktop 1685★ Rust）。
契约：computer_use.snapshot(mode:"pixels"|"a11y")；a11y 回结构化控件树（role/name/ref），ref 稳定可重试。

验收：对真实应用 a11y 能定位并点击按钮；像素模式保留；视觉模型未配置时 VISION_UNAVAILABLE 软失败。
WP4无障碍与特殊人群第一梯队

契约：主题 token 扩展 --hazard 图标/纹理冗余；aria-live 节流播报组件；voice.command.* RPC 一组（ASR/TTS provider 可插拔）；长辈模式 layout。

WP5离线 / 隐私 / 政企

10 · Security

安全合规章：设备操控专项

把 Marguerite 已有的 PlanGate / fail-closed / 回环铁律，从「操作文件」扩展到「操作物理世界」。任何物理致动不做无人值守。

设备危险四级分级（L0–L3）

L0
只读
读传感器状态、查历史。无副作用，自动执行。
L1
自动安全写
开灯、关窗帘等可逆无害操作。自动执行，事后审计。
L2
审批
开空调、锁门。走审批队列，人在回路确认。
L3
人确认 / fail-closed
开锁、动车、动机械臂、燃气水电。默认人确认，超时按拒绝。

七条红线

红线具体要求
1. 回环铁律不破统一网关永远只听 127.0.0.1；设备控制出向仅限 LAN（192.168/10.x）；任何云端设备 API（米家/Tesla）须 UI 显式标注「数据离网」并经用户授权。
2. 凭证加密隔离HA long token、米家 token、Tesla 车队私钥全部走现有 credential 加固，绝不明文落配置（对齐 R52 config 写锁）。
3. 危险分级 fail-closedL3 默认人在回路、超时按拒绝；L2 走审批队列；L1 自动；L0 只读。物理致动不做无人值守。
4. id 不接受路径设备接口只接受已登记 entity id，拒绝路径参数（对齐 R56 artifacts 安全模型），防任意读取与 DNS rebinding；跨源做同源校验 + 回环 authority 校验。
5. 跨引擎审批合并Rust 进程与 pyengine 侧车审批队列必须合并快照、裁决可转发（对齐 R54/R57），禁止「侧车抬起的审批点了没反应」。
6. 物理边界声明不直接控制医疗设备/工业 PLC；首次进入相关能力弹窗告知「需人工复核」。
7. 审计留痕谁 / 何时 / 读了哪个设备 / 下发了什么指令，全量 JSONL 落盘可导出。
