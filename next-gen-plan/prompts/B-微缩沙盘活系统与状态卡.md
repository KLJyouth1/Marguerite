# 任务书 B —— 微缩沙盘活系统 + 动态对象状态卡（Marguerite 版）

> 来源改造自「高铁桌面沙盘复刻提示词」。原提示词要求独立 Vite+React 工程；本任务书并入 **Marguerite webui（Vue3）**，作为一个新视图，核心是把「运行图驱动运动 + 点选对象显示现在/下一步状态卡」做成可复用范式。
> 落点：`webui/src/views/` 下新视图（如 `SandboxView.vue`）+ 其下逻辑模块。**禁止另起 React 工程**。

## 0. 角色与边界
你是 three.js 沙盘工程师 + 时间系统/状态机工程师。木桌 + 工程蓝图背景要与 Marguerite 岛屿风格统一（不是赛博蓝紫）。全部程序化几何 + Canvas 程序纹理（木纹/混凝土/路面/蓝图网格/站名牌），不下载外部模型贴图。

## 1. 核心吸收（从原提示词提炼，Marguerite 化）
### 1.1 视觉基调
- 一张真实木桌几何（桌面/桌腿），桌上散落工程蓝图（Canvas 画网格/总平面/尺寸线）、卷纸、尺、铅笔等少量道具——与岛屿「办公桌」风格统一。
- 暖棕木桌、暖灰混凝土、米黄/暖黄人工照明；夜景以暖光点为主，**不要蓝紫冷调**。

### 1.2 点选动态对象 → 状态卡（最关键，复用给设备/agent）
点击任意动态对象（列车/设备/agent/车辆）显示一张简洁状态卡：
- 名称 / **现在做什么（当前状态）** / **下一步做什么（下一状态）**；
- 明确高亮选中对象（outline，不改模型色）；
- 这套状态卡范式要**同时供给设备节点（任务书 A）与 agent 节点（岛屿工作台）**，做成可复用组件 `<EntityStateCard>`。

### 1.3 运行图/时刻表驱动运动（禁止匀速绕圈）
- 列车/车辆按时刻表区段运动：**起步加速 → 巡航 → 进站制动 → 停站速度严格为 0 → 开门乘降**；闭塞间隔、固定停靠点。
- 用**固定种子**让随机分布（窗灯/树/人/雨丝）与运动可精确回放——时间轴拖回同一时刻，状态必须一致（State From Time，不是只能向前的动画）。
- 车轮/受电弓随行进距离转动，车体不随车轮翻滚。

## 2. 高铁环线 = 任务流转/交通网络的离线 mock
不做十模块全尺寸复刻（那是独立工程）。本任务做**精简环线 mock** 作为「任务流转/交通网络数字孪生」的离线演示：
- 闭环双线 + 2 站 + 一段桥；3 列压缩编组按 1/3 周期错开、保持闭塞；
- 一个 294s 运行图循环（始发/越江/终到/发车/到发），停站开门。
- 白天/夜晚切换；夜景点灯真的照到地面（emissive 为主，少量 PointLight）。
- 可选小雨：**不压暗画面**（不加灰雾/全屏蒙层，只加雨丝 + 微湿反射）。

## 3. 交互契约
- 观察：orbit/pan/zoom；时间：跳转/暂停/倍速（暂停时世界冻结、相机仍可动）；
- 选择：点列车/车辆显示状态卡；聚焦只是相机行为；
- 窄屏优先保证画布/镜头/暂停可用，次要说明折叠。

## 4. 设计系统铁律
- 色值/时长/圆角走 design token；**禁裸 hex/裸 px 时长/裸 border-radius**（architecture guard 红）。
- i18n 6 语言键位对齐；无 emoji。
- 与任务书 A 共用 `<EntityStateCard>`、`FlowParticles`、木桌蓝图背景，不重复造。

## 5. 性能
- 可见渲染批次 < ~1000、三角 < ~2M；远景 InstancedMesh/合批；DPR clamp ≤2。
- 性能预算不足时降远景小物，不牺牲轨道/站台/列车/状态卡。
