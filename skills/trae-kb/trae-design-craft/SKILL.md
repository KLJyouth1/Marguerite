# 高美感界面与动效

## 先定三件事，再写一行代码

1. **气质**：科技极客 / 温暖手作 / 极简编辑 / 复古印刷 —— 选一个，不要混。
2. **层级**：用户第一眼该看到什么？第二眼？其余全部降权。
3. **节奏**：留白密度、字号级差、圆角与阴影的统一规则。

三个都没定就开始写 CSS，结果一定是「堆了很多效果但没有重点」。

## 版式

- **网格先行**：先定 8pt 间距体系，所有间距取 4/8/12/16/24/32/48/64。
- **字号级差**：至少 1.5 倍跳级（如 14 / 21 / 32 / 48），不要 15/16/17 这种肉眼无差的层级。
- **一行长度**：正文每行 45-75 字符；超过就加宽容器或分栏。
- **对齐**：同组元素共享一条基线或一条左边界；不要靠「看起来差不多」。
- **留白**：重要内容周围留白是次要内容的 2 倍以上。

## 配色

- **一个主色 + 一个辅色 + 中性灰阶**，最多再加一个语义色（成功/警告/危险）。
- 主色只用于**行动点与强调**，不要满屏铺。
- 深色界面里，用**明度差**做层级，不要用纯黑 + 纯白硬碰。
- 文字对比度：正文 ≥ 4.5:1，大标题 ≥ 3:1。
- 禁止：渐变滥用、彩虹描边、发光叠发光。

## 动效

- **动效服务于因果**：元素从哪来、到哪去、为什么变，必须能被看懂。
- 时长：微交互 120-180ms，元素进出 200-280ms，页面转场 300-400ms。
- 缓动：进场 `ease-out`，出场 `ease-in`，位移用 `cubic-bezier(0.2, 0, 0, 1)`。
- 只动 `transform` 与 `opacity`；不动 `width/height/top/left`（会触发布局抖动）。
- **尊重减少动效**：`prefers-reduced-motion` 下全部静止。
- 一屏只允许一个「主动效」，其余为辅助。

## 背景与质感（避免「简陋感」）

- 纯色背景很容易显得空：加**极低对比度的噪点/网格/径向光晕**，透明度控制在 3%-8%。
- 卡片不用重阴影，用**1px 描边 + 极轻阴影**建立层次。
- 玻璃拟态只在有明确层级需求时用，且必须保证文字可读。

## 反 AI 味清单

| 症状 | 修法 |
| --- | --- |
| 每个区块都是一模一样的卡片 | 让主区块破格（更大、跨列、不同底色） |
| 到处是渐变紫蓝 | 定一个主色，其余用中性灰阶 |
| 标题居中 + 三列图标 + 大圆角按钮 | 换一种版式：左对齐编辑式或非对称栅格 |
| 图标风格混杂 | 统一线性或统一面性，统一线宽 |
| 文案空洞（「赋能」「一站式」） | 换成具体数字与动作 |
| 动效到处飞 | 只保留引导注意力的那一处 |

## 交付时要说清

1. 用了哪套 token（颜色/字号/间距/圆角）。
2. 关键交互的状态（默认/悬停/聚焦/禁用/加载/错误/空）。
3. 响应式断点行为（窄屏怎么折叠）。
4. 可访问性：键盘可达、焦点可见、对比度达标。
5. 动效在减少动效模式下的降级。

## 验收

- [ ] 3 秒内能说出页面重点
- [ ] 字号级差肉眼可辨
- [ ] 主色只出现在行动点
- [ ] 所有交互状态都有样式
- [ ] 窄屏不横向滚动
- [ ] 减少动效模式下无动画
- [ ] 文案具体、无空话
